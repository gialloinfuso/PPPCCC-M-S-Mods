      Back to the official firmware

      • Model:Cycles: send the official model-cycles_OS1.13.syx like any OS update (from the start-up menu: hold FUNC while switching on, then OS UPGRADE).
      • Model:Samples: the official Samples OS goes back over USB in the Cycles transport: python3 tools/vendor/crossflash.py --cycles model-cycles_OS1.13.syx --samples model-samples_OS1.13.syx --back-samples makes that file (see Modded-Cycles' notes/41). The start-up menu of the Model:Samples (MIDI IN) always remains as a fallback.

      Help

      The page says my file is not the official one

      Only the official OS 1.13 files are accepted (checked by SHA-256). Download them again from elektron.se, and do not use a file that was already modified.

      “Find MIDI devices” finds nothing, or Send is not available

      Web MIDI with SysEx works in Chrome, Edge and Opera on a desktop computer; allow MIDI access when the browser asks. Connect the device over USB and close other programs that use it (Elektron Transfer, a DAW). Safari and Firefox: download the file and send it with Elektron Transfer.

      The transfer stopped or the device shows an error

      Nothing is lost: switch the device off and on, open the start-up menu (hold FUNC while switching on, then OS UPGRADE) and send the file again, with a higher “Speed” value. With a Model:Samples on the first flash, send the _smp-os file.

      Which file do I need on a Model:Samples?

      First flash (still on the Samples OS): the _smp-os.syx, from the Samples OS or its start-up menu. Later updates (a Cycles OS with the Samples key already runs): the _cyc-os.syx.

      Can I check the file myself?

      Yes: with Python, tools/build.py of the repository builds the same file from the same patches, byte for byte. The page shows the SHA-256 of the result.
